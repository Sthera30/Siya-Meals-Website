# Siya Meals Website

A website I built for a catering business, Siya Meals, to showcase her services and make it easier for customers to request quotations.

## The problem

The owner was receiving quotation requests for weddings, graduations, anniversaries and other events through WhatApp messages, which were hard to manage. She also needed an online place to show her services to new customers.

## The solution

A responsive website where customers can:

* browse the catering services on offer
* see photos of the food and events
* request a quotation for their event without having to message the owner directly

## SEO

I added search engine optimisation so that when people are searching for catering services around  Gqeberha, her website pops up.

* Page-specific titles and meta descriptions using React Helmet
* Canonical URLs to avoid duplicate content issues
* Open Graph and Twitter Card tags, so shared links show proper preview
* Structured data (JSON-LD, schema.org 'CateringService') describing the business, its location and service are
* a 'sitemap.xml' and 'robos.txt' to help search engines crawl the site
* Descriptive alt text on images

## Tech stack

* React.js
* HTML, CSS, JavaScript
